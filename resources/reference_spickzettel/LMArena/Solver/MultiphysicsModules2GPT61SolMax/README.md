# VECTOR / Cluster C

An interactive React, Vite, and Tailwind CSS multiphysics workbench with a
dependency-free C++20 numerical reference implementation.

## Start the Workbench

```sh
npm install
npm run dev
```

`npm run build` creates the production app in `dist/`. Serve it with
`npm run preview`; opening the HTML directly as a file will not provide the
HTTP paths used for source downloads and the verification report.

## What Is Included

- Battery: 2-RC ECM, temperature-dependent OCV, signed entropic/overpotential
  terms, four-stage positive Arrhenius source integration, and pack telemetry.
- Aeroacoustics: FWH/Curle source and receiver inspection, Hann-windowed radix-2
  spectra, complete 1/3-octave bands, and OASPL.
- MHD: Hartmann profile exploration, a current-conservative native potential
  solve, face-moment current reconstruction, Lorentz coupling, and Joule heating.
- TPS: pyrolysis, wall balance, 3D porous-solid sources and Darcy blowing, plus
  native BDF2 ALE motion, exact swept-face volume integration, and DGCL checks.
- Interactive field inspection, adjustable parameters, playback and time
  scrubbing, saved local run snapshots, CSV/JSON export, a topology inspector,
  native source downloads, and separate native/browser verification reports.

## Verify the Native Code

```sh
bash scripts/verify-native.sh
```

This compiles `public/solver/cluster_c.cpp` with g++ C++20 and `-O2`, executes the
native tests and all four demonstrations, and refreshes
`public/verification.json`. Rebuild the website after refreshing this report.
The source can also compile independently with the command shown in the app.

The full ABI, numerical assumptions, references, and limitations are documented
in `public/solver/README.md` and the Source & API view.

## Verify the Interface

With the dev server running:

```sh
npx playwright install --with-deps chromium
node scripts/check-workbench.mjs
```

Set `BASE_URL` to check a different running server, including the production
preview. The script exercises module navigation, parameters, cell/microphone
selection, playback, run saving/restoring, downloads, browser checks, source
inspection, and a mobile viewport. Screenshots are written to `artifacts/`.

## Execution and Engineering Scope

Browser plots execute independent TypeScript reference kernels. They do not
claim a connection to a native process or HPC cluster. The downloadable native
report is generated by an actual native compile/run, not by the browser.

The proprietary CAbiSpan ABI and the host solver's integration interfaces were
not supplied, so this reference provides an explicit non-owning SoA adapter.
It is not an assertion of binary compatibility with unknown data structures.

The material coefficients are illustrative, and numerical verification is not
experimental validation. Coolant CFD, a production implicit high-Ha momentum
scheme, and monolithic 3D moving-mesh TPS validation are not claimed. The native
code contains reusable 3D porous/geometry kernels and a coupled 1D ALE TPS demo.
Use the detailed model contracts before adapting this for engineering work.
