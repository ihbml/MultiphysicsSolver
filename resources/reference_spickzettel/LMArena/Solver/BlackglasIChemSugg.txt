Multiphysics Chemistry Solver Recommendations (Rust / C++)
TL;DR

No single off-the-shelf tool covers "multiphysics + chemistry + micro + macro" perfectly, because microscale (atomistic/molecular) and macroscale (continuum PDE) simulations are fundamentally different numerical problems. The professional answer is a C++ stack of specialized, exascale-proven solvers, coupled together — and that's where I'd put you. Rust has exciting but very young entrants (2025–2026 era) that are promising but not yet at "very performant at scale" maturity. Details below.
1. Why the C++ ecosystem wins on "very performant" today

The C++ tools below have published exascale benchmarks, GPU backends, and decades of validation. The Rust equivalents are alpha-stage with limited or no GPU support.

5. Final advice

    Pick C++ for the solvers, period — if "very performant" is a hard requirement, the validated performance ceiling (Kokkos/exascale LAMMPS, GPU OpenFOAM, 100k-core MOOSE) is far ahead of anything in Rust right now.
    Don't expect one binary — the field's answer to "micro + macro + multiphysics + chemistry" is a coupled stack: LAMMPS (micro) + OpenFOAM or MOOSE (macro) + Cantera (kinetics core), with MOOSE MultiApp or MUI handling the handshake.
    If you must use Rust, go OxiPhysics + Cantera-FFI, and budget for alpha-stage gaps (GPU, MPI, kinetics). Revisit in 12 months — the Rust HPC-sim ecosystem is moving fast.
