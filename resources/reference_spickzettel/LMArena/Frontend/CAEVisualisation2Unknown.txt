# Paket 3 (`CFDFLD03`) — In-Situ Post-Processing & Streaming Engine

Production-grade reference implementation for an ultra-low-latency, zero-copy in-situ post-processing and streaming stack. It targets:
- **Solver side:** C++20 (producer, kernels, integrals, telemetry emission)
- **Frontend/IO side:** Rust (`foam_fast_io`, SPMC consumer, delta streamer, wgpu-ready buffers)
- **Inspector:** interactive HTML app (protocol/header inspector, architecture view, live micro-benchmarks)

> **Build notes (representative):**
> - C++20: `-std=c++20 -O3 -march=native -pthread` (+ `-lz4` / `-lzfp` / `ws2_32` on Windows as needed)
> - Rust: `tokio`, `bytemuck`, `lz4_flex`, `tokio-tungstenite`, `quinn` (optional), `wgpu` (frontend)
> - Packet endianness: **little-endian** for all multi-byte fields (x86/ARM64 HPC norm). Validate `magic` and `endianness_tag` when bridging.

## 1) `CFDFLD03` binary protocol (bit-exact 64-byte header) + Hilbert chunk directory

### 1.1 C++20 protocol header (`include/cfdfld03/protocol.hpp`)

```cpp
#pragma once
#include <array>
#include <bit>
#include <cstddef>
#include <cstdint>
#include <cstring>
#include <type_traits>

namespace cfdfld03 {

static constexpr std::array<char,8> kMagic = {'C','F','D','F','L','D','0','3'};
static constexpr uint16_t kHeaderVersion = 1;
static constexpr uint16_t kHeaderSize = 64;
static constexpr uint32_t kHilbertChunkCells = 65536u; // 2^16

enum class FieldLocation : uint8_t {
    Cell          = 0,
    Point         = 1,
    Face          = 2,
    BoundaryPatch = 3
};

enum class ValueSource : uint8_t {
    BoundaryField     = 0,
    OwnerCellFallback = 1
};

enum class ScalarType : uint8_t {
    F32 = 0,
    F64 = 1
};

enum Compression : uint8_t {
    CMP_NONE       = 0u,
    CMP_LZ4        = 1u << 0,
    CMP_ZFP        = 1u << 1, // error-bounded block compression (ZFP or compatible)
    CMP_XOR_DELTA  = 1u << 2, // XOR-delta on IEEE-754 bit patterns before block compression
    CMP_QUANTIZED  = 1u << 3  // optional error-bounded linear quantization pre-pass
};

#pragma pack(push, 1)
struct Header {
    char     magic[8];            // 0  : "CFDFLD03"
    uint32_t mesh_revision;       // 8  : increments on topology/mapping change
    uint32_t chunk_count;         // 12 : number of Hilbert chunks in directory
    uint64_t step_index;          // 16 : solver step / iteration
    double   sim_time_f64;        // 24 : simulation time [s]
    int8_t   dims[7];             // 32 : SI exponents [kg,m,s,K,mol,A,cd]
    uint8_t  field_location;      // 39 : FieldLocation
    uint8_t  value_source;        // 40 : ValueSource
    uint8_t  compression;         // 41 : Compression bitmask
    uint8_t  scalar_type;         // 42 : ScalarType
    uint8_t  components;          // 43 : 1 scalar, 3 vector, 9 tensor, ...
    uint16_t chunk_shift;         // 44 : 16 => 65,536 cells/chunk
    uint16_t header_version;      // 46 : = kHeaderVersion
    uint64_t total_values;        // 48 : total elements (cells/points/faces * components)
    uint32_t chunk_dir_offset;    // 56 : bytes from packet/slot base to ChunkEntry[chunk_count]
    uint32_t payload_offset;      // 60 : bytes from packet/slot base to compressed/raw payload region
};
#pragma pack(pop)

static_assert(sizeof(Header) == 64, "CFDFLD03 header must be 64 bytes");
static_assert(std::is_trivially_copyable_v<Header>);
static_assert(std::endian::native == std::endian::little, "This reference assumes little-endian hosts");

// Chunk directory entry: enables Hilbert chunk skipping (AABB) and random access.
// One entry per 65,536-cell Hilbert chunk (or partial tail chunk).
#pragma pack(push, 1)
struct ChunkEntry {
    uint64_t data_offset;     // absolute or payload-relative offset (convention: slot-base absolute)
    uint32_t data_bytes;      // compressed/stored bytes for this chunk payload
    uint32_t raw_bytes;       // uncompressed bytes
    uint32_t cell_begin;      // first cell index in Hilbert/global ordering
    uint32_t cell_end;        // one-past-last cell index
    uint32_t hilbert_index;   // chunk id in Hilbert curve order
    uint32_t flags;           // per-chunk flags (e.g. all-NaN masked, constant, etc.)
    float    aabb_min[3];     // chunk spatial AABB for plane/frustum/iso skipping
    float    aabb_max[3];
    float    value_min;       // scalar min (or magnitude min) for iso/culling hints
    float    value_max;       // scalar max
};
#pragma pack(pop)

static_assert(sizeof(ChunkEntry) == 64, "ChunkEntry expected 64 bytes for alignment/cache friendliness");

// Slot envelope stored at the beginning of each SHM slot / stream frame.
#pragma pack(push, 1)
struct SlotEnvelope {
    uint64_t frame_sequence;   // monotonic commit sequence
    uint64_t payload_bytes;    // total bytes valid in this slot (header + dir + payload)
    uint64_t wall_clock_ns;    // producer CLOCK_MONOTONIC_RAW or UTC ns
    uint32_t checksum_crc32c;  // optional (0 if disabled)
    uint32_t reserved;
    Header   header;           // CFDFLD03 header
};
#pragma pack(pop)

static_assert(sizeof(SlotEnvelope) == 96);

inline bool validate_header(const Header& h) {
    if (std::memcmp(h.magic, kMagic.data(), 8) != 0) return false;
    if (h.header_version != kHeaderVersion) return false;
    if (h.chunk_shift != 16) return false; // 65,536-cell chunks required by Paket 3
    if (h.components == 0) return false;
    if (h.field_location > static_cast<uint8_t>(FieldLocation::BoundaryPatch)) return false;
    if (h.value_source > static_cast<uint8_t>(ValueSource::OwnerCellFallback)) return false;
    return true;
}

inline size_t scalar_size_bytes(ScalarType t) {
    return (t == ScalarType::F64) ? 8u : 4u;
}

} // namespace cfdfld03
```

## 2) Lock-free SPMC shared-memory ring (triple-buffered, latest-frame friendly)

Design: fixed-size slots in named shared memory. Producer writes a slot, sets `sequence` to odd (writing), writes payload, commits with even `sequence = published+2` (release). Readers load `published_sequence` (acquire), copy/inspect slot, verify sequence unchanged before/after (seqlock). With `slot_count=3`, consumers always get the newest completed frame with no producer blocking (triple-buffer/mailbox semantics). Larger rings preserve short history.

### 2.1 C++20 SHM ring (`include/cfdfld03/shm_ring.hpp`)

```cpp
#pragma once
#include "protocol.hpp"
#include <atomic>
#include <cstdint>
#include <string>
#include <stdexcept>
#include <algorithm>
#include <thread>

#if defined(_WIN32)
  #define NOMINMAX
  #include <windows.h>
#else
  #include <sys/mman.h>
  #include <sys/stat.h>
  #include <fcntl.h>
  #include <unistd.h>
#endif

namespace cfdfld03::shm {

static constexpr uint64_t kShmMagic = 0x434644334653484DuULL; // "CFD3FSHM"
static constexpr uint32_t kCacheLine = 64;

struct alignas(64) SlotControl {
    std::atomic<uint64_t> sequence{0}; // 0 empty, odd writing, even committed
    std::atomic<uint32_t> active_readers{0};
    uint32_t bytes_used{0};
    uint64_t reserved{0};
};
static_assert(sizeof(SlotControl) == 64);

struct alignas(64) ShmControl {
    uint64_t magic{kShmMagic};
    uint32_t abi_version{1};
    uint32_t slot_count{0};
    uint32_t slot_payload_bytes{0};
    uint32_t envelope_bytes{static_cast<uint32_t>(sizeof(SlotEnvelope))};
    std::atomic<uint64_t> published_sequence{0};
    std::atomic<uint64_t> dropped_frames{0};
    std::atomic<uint32_t> writer_pid{0};
    uint32_t reserved0{0};
    uint8_t  pad[64 - 40]; // keep control header/cache behavior explicit
};
static_assert(sizeof(ShmControl) == 64);

inline size_t control_region_size(uint32_t slot_count) {
    return sizeof(ShmControl) + slot_count * sizeof(SlotControl);
}
inline size_t total_shm_size(uint32_t slot_count, uint32_t slot_payload_bytes) {
    const size_t slot_stride = sizeof(SlotEnvelope) + slot_payload_bytes;
    return control_region_size(slot_count) + slot_count * slot_stride;
}

class MappedRegion {
public:
    MappedRegion() = default;
    MappedRegion(const MappedRegion&) = delete;
    MappedRegion& operator=(const MappedRegion&) = delete;
    MappedRegion(MappedRegion&& o) noexcept { *this = std::move(o); }
    MappedRegion& operator=(MappedRegion&& o) noexcept {
        if (this != &o) { close(); ptr_=o.ptr_; size_=o.size_; name_=std::move(o.name_);
#if defined(_WIN32)
            hMap_=o.hMap_; o.hMap_=nullptr;
#else
            fd_=o.fd_; owner_=o.owner_; o.fd_=-1; o.owner_=false;
#endif
            o.ptr_=nullptr; o.size_=0; }
        return *this;
    }
    ~MappedRegion() { close(); }

    static MappedRegion create(const std::string& name, size_t bytes) {
        MappedRegion r; r.name_ = name; r.size_ = bytes;
#if defined(_WIN32)
        r.hMap_ = CreateFileMappingA(INVALID_HANDLE_VALUE, nullptr, PAGE_READWRITE,
                                     (DWORD)(bytes >> 32), (DWORD)(bytes & 0xFFFFFFFFu), name.c_str());
        if (!r.hMap_) throw std::runtime_error("CreateFileMapping failed");
        r.ptr_ = MapViewOfFile(r.hMap_, FILE_MAP_ALL_ACCESS, 0, 0, bytes);
        if (!r.ptr_) { CloseHandle(r.hMap_); r.hMap_=nullptr; throw std::runtime_error("MapViewOfFile failed"); }
        std::memset(r.ptr_, 0, bytes);
#else
        r.fd_ = shm_open(name.c_str(), O_CREAT | O_RDWR, 0660);
        if (r.fd_ < 0) throw std::runtime_error("shm_open failed");
        if (ftruncate(r.fd_, static_cast<off_t>(bytes)) != 0) { ::close(r.fd_); r.fd_=-1; throw std::runtime_error("ftruncate failed"); }
        r.ptr_ = mmap(nullptr, bytes, PROT_READ | PROT_WRITE, MAP_SHARED, r.fd_, 0);
        if (r.ptr_ == MAP_FAILED) { ::close(r.fd_); r.fd_=-1; r.ptr_=nullptr; throw std::runtime_error("mmap failed"); }
        r.owner_ = true;
        std::memset(r.ptr_, 0, bytes);
#endif
        return r;
    }

    static MappedRegion open(const std::string& name, size_t bytes) {
        MappedRegion r; r.name_ = name; r.size_ = bytes;
#if defined(_WIN32)
        r.hMap_ = OpenFileMappingA(FILE_MAP_ALL_ACCESS, FALSE, name.c_str());
        if (!r.hMap_) throw std::runtime_error("OpenFileMapping failed");
        r.ptr_ = MapViewOfFile(r.hMap_, FILE_MAP_ALL_ACCESS, 0, 0, bytes);
        if (!r.ptr_) { CloseHandle(r.hMap_); r.hMap_=nullptr; throw std::runtime_error("MapViewOfFile failed"); }
#else
        r.fd_ = shm_open(name.c_str(), O_RDWR, 0660);
        if (r.fd_ < 0) throw std::runtime_error("shm_open open failed");
        r.ptr_ = mmap(nullptr, bytes, PROT_READ | PROT_WRITE, MAP_SHARED, r.fd_, 0);
        if (r.ptr_ == MAP_FAILED) { ::close(r.fd_); r.fd_=-1; r.ptr_=nullptr; throw std::runtime_error("mmap open failed"); }
#endif
        return r;
    }

    void close() {
        if (!ptr_) return;
#if defined(_WIN32)
        UnmapViewOfFile(ptr_);
        if (hMap_) CloseHandle(hMap_);
        hMap_ = nullptr;
#else
        munmap(ptr_, size_);
        if (fd_ >= 0) ::close(fd_);
        if (owner_ && !name_.empty()) shm_unlink(name_.c_str());
        fd_ = -1; owner_ = false;
#endif
        ptr_ = nullptr; size_ = 0;
    }

    void* data() const { return ptr_; }
    size_t size() const { return size_; }

private:
    void* ptr_{nullptr};
    size_t size_{0};
    std::string name_;
#if defined(_WIN32)
    HANDLE hMap_{nullptr};
#else
    int fd_{-1};
    bool owner_{false};
#endif
};

class ProducerRing {
public:
    ProducerRing(std::string name, uint32_t slot_count, uint32_t slot_payload_bytes)
        : name_(std::move(name)), slot_count_(slot_count), slot_payload_bytes_(slot_payload_bytes),
          region_(MappedRegion::create(name_, total_shm_size(slot_count, slot_payload_bytes))) {
        ctrl_ = reinterpret_cast<ShmControl*>(region_.data());
        ctrl_->magic = kShmMagic;
        ctrl_->slot_count = slot_count;
        ctrl_->slot_payload_bytes = slot_payload_bytes;
        ctrl_->published_sequence.store(0, std::memory_order_relaxed);
#if defined(_WIN32)
        ctrl_->writer_pid.store((uint32_t)GetCurrentProcessId(), std::memory_order_relaxed);
#else
        ctrl_->writer_pid.store((uint32_t)getpid(), std::memory_order_relaxed);
#endif
        slots_ = reinterpret_cast<SlotControl*>((uint8_t*)region_.data() + sizeof(ShmControl));
        data_base_ = (uint8_t*)region_.data() + control_region_size(slot_count);
    }

    // Returns writable slot memory (SlotEnvelope + payload area). Commit after filling.
    uint8_t* begin_write(uint64_t& out_sequence, uint32_t& out_slot_index) {
        const uint64_t next = ctrl_->published_sequence.load(std::memory_order_relaxed) + 2;
        out_sequence = next;
        out_slot_index = static_cast<uint32_t>((next / 2) % slot_count_);
        auto& s = slots_[out_slot_index];
        s.sequence.store(next - 1, std::memory_order_release); // odd = writing
        s.active_readers.store(0, std::memory_order_relaxed);
        return slot_ptr(out_slot_index);
    }

    void commit_write(uint32_t slot_index, uint64_t sequence, uint32_t bytes_used) {
        auto& s = slots_[slot_index];
        s.bytes_used = bytes_used;
        std::atomic_thread_fence(std::memory_order_release);
        s.sequence.store(sequence, std::memory_order_release); // even = committed
        ctrl_->published_sequence.store(sequence, std::memory_order_release);
    }

    uint32_t slot_payload_bytes() const { return slot_payload_bytes_; }
    uint32_t slot_count() const { return slot_count_; }

private:
    uint8_t* slot_ptr(uint32_t idx) const {
        const size_t stride = sizeof(SlotEnvelope) + slot_payload_bytes_;
        return data_base_ + idx * stride;
    }

    std::string name_;
    uint32_t slot_count_{};
    uint32_t slot_payload_bytes_{};
    MappedRegion region_;
    ShmControl* ctrl_{nullptr};
    SlotControl* slots_{nullptr};
    uint8_t* data_base_{nullptr};
};

class ConsumerRing {
public:
    ConsumerRing(std::string name, uint32_t slot_count, uint32_t slot_payload_bytes)
        : region_(MappedRegion::open(name, total_shm_size(slot_count, slot_payload_bytes))) {
        ctrl_ = reinterpret_cast<ShmControl*>(region_.data());
        if (ctrl_->magic != kShmMagic) throw std::runtime_error("SHM magic mismatch");
        slot_count_ = ctrl_->slot_count;
        slot_payload_bytes_ = ctrl_->slot_payload_bytes;
        slots_ = reinterpret_cast<SlotControl*>((uint8_t*)region_.data() + sizeof(ShmControl));
        data_base_ = (uint8_t*)region_.data() + control_region_size(slot_count_);
    }

    // SPMC latest-frame read: copies latest committed slot into out buffer with seqlock validation.
    // Returns true if a stable frame was copied.
    bool read_latest(std::vector<uint8_t>& out, uint64_t& out_sequence) {
        for (int attempt = 0; attempt < 8; ++attempt) {
            const uint64_t pub = ctrl_->published_sequence.load(std::memory_order_acquire);
            if (pub == 0 || (pub & 1ull)) continue;
            const uint32_t idx = static_cast<uint32_t>((pub / 2) % slot_count_);
            auto& s = slots_[idx];
            const uint64_t seq1 = s.sequence.load(std::memory_order_acquire);
            if (seq1 != pub) continue;
            const uint32_t bytes = s.bytes_used;
            if (bytes == 0 || bytes > sizeof(SlotEnvelope) + slot_payload_bytes_) continue;

            out.resize(bytes);
            std::memcpy(out.data(), slot_ptr(idx), bytes);
            std::atomic_thread_fence(std::memory_order_acquire);
            const uint64_t seq2 = s.sequence.load(std::memory_order_acquire);
            if (seq1 == seq2 && (seq2 & 1ull) == 0) {
                out_sequence = seq2;
                last_seen_ = seq2;
                return true;
            }
        }
        return false;
    }

    bool has_new_frame() const {
        return ctrl_->published_sequence.load(std::memory_order_acquire) != last_seen_;
    }

private:
    uint8_t* slot_ptr(uint32_t idx) const {
        const size_t stride = sizeof(SlotEnvelope) + slot_payload_bytes_;
        return data_base_ + idx * stride;
    }

    MappedRegion region_;
    ShmControl* ctrl_{nullptr};
    SlotControl* slots_{nullptr};
    uint8_t* data_base_{nullptr};
    uint32_t slot_count_{0};
    uint32_t slot_payload_bytes_{0};
    uint64_t last_seen_{0};
};

} // namespace cfdfld03::shm
```

```rust
#[cfg(unix)]
mod posix {
    use super::*;

    pub struct Mapping {
        ptr: *mut u8,
        len: usize,
        name: CString,
        owner: bool,
    }
    unsafe impl Send for Mapping {}
    unsafe impl Sync for Mapping {}

    impl Mapping {
        pub unsafe fn create(name: &str, len: usize) -> io::Result<Self> {
            let cname = CString::new(name).unwrap();
            let fd = libc::shm_open(cname.as_ptr(), libc::O_CREAT | libc::O_RDWR, 0o660);
            if fd < 0 { return Err(io::Error::last_os_error()); }
            if libc::ftruncate(fd, len as libc::off_t) != 0 {
                libc::close(fd); return Err(io::Error::last_os_error());
            }
            let ptr = libc::mmap(ptr::null_mut(), len, libc::PROT_READ | libc::PROT_WRITE, libc::MAP_SHARED, fd, 0);
            libc::close(fd);
            if ptr == libc::MAP_FAILED { return Err(io::Error::last_os_error()); }
            ptr::write_bytes(ptr as *mut u8, 0, len);
            Ok(Self { ptr: ptr as *mut u8, len, name: cname, owner: true })
        }

            let cname = CString::new(name).unwrap();

            if fd < 0 { return Err(io::Error::last_os_error()); }
            let ptr = libc::mmap(ptr::null_mut(), len, libc::PROT_READ | libc::PROT_WRITE, libc::MAP_SHARED, fd, 0);
            libc::close(fd);

        }

                if self.owner { libc::shm_unlink(self.name.as_ptr()); }

        }
    }
}

#[cfg(unix)]
pub use posix::Mapping;

pub struct ConsumerRing {
    map: Mapping,
    slot_count: usize,
    slot_stride: usize,
    last_seen: u64,
}

impl ConsumerRing {
    /// `len` must match producer's total_shm_size(slot_count, slot_payload_bytes)
    pub unsafe fn open(name: &str, len: usize) -> io::Result<Self> {
        let map = Mapping::open(name, len)?;
        let ctrl = &*(map.as_ptr() as *const ShmControl);
        if ctrl.magic != SHM_MAGIC { return Err(io::Error::new(io::ErrorKind::InvalidData, "SHM magic mismatch")); }
        let slot_count = ctrl.slot_count as usize;
        let slot_stride = core::mem::size_of::<SlotEnvelope>() + ctrl.slot_payload_bytes as usize;
        Ok(Self { map, slot_count, slot_stride, last_seen: 0 })
    }

    pub fn read_latest(&mut self) -> Option<Vec<u8>> {
        unsafe {
            let base = self.map.as_ptr();
            let ctrl = &*(base as *const ShmControl);
            for _ in 0..8 {
                let pub_seq = ctrl.published_sequence.load(Ordering::Acquire);
                if pub_seq == 0 || pub_seq & 1 == 1 { continue; }
                let idx = ((pub_seq / 2) as usize) % self.slot_count;
                let slots_base = base.add(core::mem::size_of::<ShmControl>()) as *const SlotControl;
                let slot = &*slots_base.add(idx);
                let seq1 = slot.sequence.load(Ordering::Acquire);
                if seq1 != pub_seq { continue; }
                let bytes = slot.bytes_used as usize;
                if bytes == 0 || bytes > self.slot_stride { continue; }
                let data_base = base.add(core::mem::size_of::<ShmControl>() + self.slot_count * core::mem::size_of::<SlotControl>());
                let src = data_base.add(idx * self.slot_stride);
                let mut out = vec![0u8; bytes];
                core::ptr::copy_nonoverlapping(src, out.as_mut_ptr(), bytes);
                core::sync::atomic::fence(Ordering::Acquire);
                let seq2 = slot.sequence.load(Ordering::Acquire);
                if seq1 == seq2 && seq2 & 1 == 0 {
                    self.last_seen = seq2;
                    return Some(out);
                }
            }
            None
        }
    }
}
```

### 3.1 Delta + compression core (Rust, `crates/foam_fast_io/src/delta_stream.rs`)

```rust
use crate::protocol::{compression, Cfdfld03Header, ScalarType};
use lz4_flex::block::{compress_prepend_size, decompress_size_prepended};
use tokio::sync::mpsc;

#[derive(Clone, Debug)]
pub struct StreamFrame {
    pub header: Cfdfld03Header,
    pub chunk_entries: Vec<u8>,  // raw serialized directory (or compressed, per flag policy)
    pub payload: Vec<u8>,        // compressed payload
    pub sequence: u64,
}

pub struct XorDeltaState {
    prev: Vec<u8>, // previous raw IEEE-754 bytes for a field/stream
}

impl XorDeltaState {
    pub fn new() -> Self { Self { prev: Vec::new() } }

    /// Applies XOR-delta in-place over 4- or 8-byte lanes and returns delta buffer.
    pub fn encode(&mut self, raw_ieee_bytes: &[u8], scalar_type: u8) -> Vec<u8> {
        let lane = if scalar_type == ScalarType::F64 as u8 { 8 } else { 4 };
        if self.prev.len() != raw_ieee_bytes.len() {
            self.prev.clear();
            self.prev.resize(raw_ieee_bytes.len(), 0);
        }
        let mut delta = vec![0u8; raw_ieee_bytes.len()];
        for (i, d) in delta.iter_mut().enumerate() {
            *d = raw_ieee_bytes[i] ^ self.prev[i];
        }
        // lane-wise XOR already done bytewise; equivalent for IEEE-754 bit patterns.
        let _ = lane; // semantic marker; bytewise XOR is identical
        self.prev.copy_from_slice(raw_ieee_bytes);
        delta
    }

    pub fn decode(&mut self, delta_bytes: &[u8], scalar_type: u8) -> Vec<u8> {
        let lane = if scalar_type == ScalarType::F64 as u8 { 8 } else { 4 };
        if self.prev.len() != delta_bytes.len() {
            self.prev.clear();
            self.prev.resize(delta_bytes.len(), 0);
        }
        let mut raw = vec![0u8; delta_bytes.len()];
        for i in 0..delta_bytes.len() {
            raw[i] = delta_bytes[i] ^ self.prev[i];
        }
        let _ = lane;
        self.prev.copy_from_slice(&raw);
        raw
    }
}

pub fn compress_payload(mut raw: Vec<u8>, header: &Cfdfld03Header, delta: &mut Option<XorDeltaState>) -> Result<Vec<u8>, String> {
    let mut buf = raw;
    if header.compression & compression::XOR_DELTA != 0 {
        let st = delta.get_or_insert_with(XorDeltaState::new);
        buf = st.encode(&buf, header.scalar_type);
    }
    if header.compression & compression::ZFP != 0 {
        // Production path: call ZFP (error-bounded) via FFI (zfp_stream_set_accuracy / set_rate).
        // Here we provide an error-bounded quantization+LZ4 fallback hook when ZFP is unavailable.
        // Replace this block with zfp_compress(...) in deployments requiring strict ZFP wire compatibility.
        buf = quantize_error_bounded_block(&buf, header.scalar_type, 1e-4 /* example abs tol */)?;
        buf = compress_prepend_size(&buf);
    } else if header.compression & compression::LZ4 != 0 {
        buf = compress_prepend_size(&buf);
    }
    Ok(buf)
}

pub fn decompress_payload(mut data: Vec<u8>, header: &Cfdfld03Header, delta: &mut Option<XorDeltaState>) -> Result<Vec<u8>, String> {
    let mut buf = data;
    if header.compression & compression::ZFP != 0 {
        buf = decompress_size_prepended(&buf).map_err(|e| e.to_string())?;
        buf = dequantize_error_bounded_block(&buf, header.scalar_type)?;
    } else if header.compression & compression::LZ4 != 0 {
        buf = decompress_size_prepended(&buf).map_err(|e| e.to_string())?;
    }
    if header.compression & compression::XOR_DELTA != 0 {
        let st = delta.get_or_insert_with(XorDeltaState::new);
        buf = st.decode(&buf, header.scalar_type);
    }
    Ok(buf)
}

/// Simple error-bounded block quantizer (fallback): stores scale+q_i16 lanes.
/// For production ZFP, swap with libzfp FFI; protocol flag CMP_ZFP indicates error-bounded mode.
fn quantize_error_bounded_block(raw: &[u8], scalar_type: u8, abs_tol: f64) -> Result<Vec<u8>, String> {
    // Fallback wire format: [u8 scalar_type][f64 abs_tol][u64 count][f32 scale][i16 quantized...]
    // (Not ZFP bitstream-compatible; used only when HAVE_ZFP is off. Keep flagging explicit in deployment.)
    if scalar_type == ScalarType::F64 as u8 {
        let count = raw.len() / 8;
        let mut out = Vec::with_capacity(1 + 8 + 8 + 4 + count * 2);
        out.push(scalar_type); out.extend_from_slice(&abs_tol.to_le_bytes()); out.extend_from_slice(&(count as u64).to_le_bytes());
        let vals: Vec<f64> = raw.chunks_exact(8).map(|c| f64::from_le_bytes(c.try_into().unwrap())).collect();
        let max_abs = vals.iter().fold(0.0f64, |a, v| a.max(v.abs())).max(abs_tol);
        let scale = (max_abs / 32767.0).max(abs_tol) as f32;
        out.extend_from_slice(&scale.to_le_bytes());
        for v in vals {
            let q = ((v / scale as f64).round().clamp(-32768.0, 32767.0)) as i16;
            out.extend_from_slice(&q.to_le_bytes());
        }
        Ok(out)
    } else {
        let count = raw.len() / 4;
        let mut out = Vec::with_capacity(1 + 8 + 8 + 4 + count * 2);
        out.push(scalar_type); out.extend_from_slice(&abs_tol.to_le_bytes()); out.extend_from_slice(&(count as u64).to_le_bytes());
        let vals: Vec<f32> = raw.chunks_exact(4).map(|c| f32::from_le_bytes(c.try_into().unwrap())).collect();
        let max_abs = vals.iter().fold(0.0f32, |a, v| a.max(v.abs())).max(abs_tol as f32);
        let scale = (max_abs / 32767.0).max(abs_tol as f32);
        out.extend_from_slice(&scale.to_le_bytes());
        for v in vals {
            let q = ((v / scale).round().clamp(-32768.0, 32767.0)) as i16;
            out.extend_from_slice(&q.to_le_bytes());
        }
        Ok(out)
    }
}

fn dequantize_error_bounded_block(buf: &[u8], _scalar_type: u8) -> Result<Vec<u8>, String> {
    if buf.len() < 1 + 8 + 8 + 4 { return Err("quantized block too small".into()); }
    let st = buf[0];
    let count = u64::from_le_bytes(buf[9..17].try_into().unwrap()) as usize;
    let scale = f32::from_le_bytes(buf[17..21].try_into().unwrap()) as f64;
    let mut q = &buf[21..];
    if st == ScalarType::F64 as u8 {
        let mut out = Vec::with_capacity(count * 8);
        for _ in 0..count {
            let qi = i16::from_le_bytes(q[0..2].try_into().unwrap()) as f64; q = &q[2..];
            out.extend_from_slice(&(qi * scale).to_le_bytes());
        }
        Ok(out)
    } else {
        let mut out = Vec::with_capacity(count * 4);
        for _ in 0..count {
            let qi = i16::from_le_bytes(q[0..2].try_into().unwrap()) as f64; q = &q[2..];
            out.extend_from_slice(&((qi * scale) as f32).to_le_bytes());
        }
        Ok(out)
    }
}

// --- WebSocket streamer (async, Tokio + tungstenite) ---
pub async fn run_ws_streamer(bind: &str, mut rx: mpsc::Receiver<StreamFrame>) -> anyhow::Result<()> {
    use tokio::net::TcpListener;
    use tokio_tungstenite::accept_async;
    use futures_util::{SinkExt, StreamExt};
    use std::sync::Arc;
    use tokio::sync::broadcast;

    let listener = TcpListener::bind(bind).await?;
    let (btx, _) = broadcast::channel::<Arc<Vec<u8>>>(8);

    let btx_fwd = btx.clone();
    tokio::spawn(async move {
        while let Some(frame) = rx.recv().await {
            // Wire: [u64 seq][u32 header_len][u32 entries_len][u32 payload_len][header][entries][payload]
            let header_bytes = unsafe {
                std::slice::from_raw_parts(&frame.header as *const _ as *const u8, std::mem::size_of::<Cfdfld03Header>())
            };
            let mut msg = Vec::with_capacity(20 + header_bytes.len() + frame.chunk_entries.len() + frame.payload.len());
            msg.extend_from_slice(&frame.sequence.to_le_bytes());
            msg.extend_from_slice(&(header_bytes.len() as u32).to_le_bytes());
            msg.extend_from_slice(&(frame.chunk_entries.len() as u32).to_le_bytes());
            msg.extend_from_slice(&(frame.payload.len() as u32).to_le_bytes());
            msg.extend_from_slice(header_bytes);
            msg.extend_from_slice(&frame.chunk_entries);
            msg.extend_from_slice(&frame.payload);
            let _ = btx_fwd.send(Arc::new(msg)); // drop-old under backpressure (lagging clients)
        }
    });

    loop {
        let (stream, _) = listener.accept().await?;
        let mut brx = btx.subscribe();
        tokio::spawn(async move {
            if let Ok(mut ws) = accept_async(stream).await {
                loop {
                    match brx.recv().await {
                        Ok(msg) => {
                            if ws.send(tokio_tungstenite::tungstenite::Message::Binary((*msg).clone())).await.is_err() { break; }
                        }
                        Err(tokio::sync::broadcast::error::RecvError::Lagged(_)) => continue, // live: skip to newest
                        Err(_) => break,
                    }
                }
            }
        });
    }
}
```

```cpp
#pragma once
#include "protocol.hpp"
#include <vector>
#include <cstdint>
#include <cstring>
#include <algorithm>
#include <stdexcept>

#ifdef CFD_ENABLE_LZ4
#include <lz4.h>
#endif
#ifdef CFD_ENABLE_ZFP
#include <zfp.h>
#endif

namespace cfdfld03::stream {

struct XorDeltaState {
    std::vector<uint8_t> prev;

    void encode(const uint8_t* raw, size_t n, std::vector<uint8_t>& delta_out) {
        if (prev.size() != n) prev.assign(n, 0);
        delta_out.resize(n);
        for (size_t i = 0; i < n; ++i) delta_out[i] = raw[i] ^ prev[i];
        std::memcpy(prev.data(), raw, n);
    }
    void decode(const uint8_t* delta, size_t n, std::vector<uint8_t>& raw_out) {
        if (prev.size() != n) prev.assign(n, 0);
        raw_out.resize(n);
        for (size_t i = 0; i < n; ++i) raw_out[i] = delta[i] ^ prev[i];
        std::memcpy(prev.data(), raw_out.data(), n);
    }
};

inline std::vector<uint8_t> lz4_compress(const std::vector<uint8_t>& in) {
#ifdef CFD_ENABLE_LZ4
    const int max_dst = LZ4_compressBound(static_cast<int>(in.size()));
    std::vector<uint8_t> out(4 + max_dst);
    std::memcpy(out.data(), &in, 0); // placeholder
    uint32_t sz = static_cast<uint32_t>(in.size());
    std::memcpy(out.data(), &sz, 4);
    int csz = LZ4_compress_default(reinterpret_cast<const char*>(in.data()),
                                   reinterpret_cast<char*>(out.data() + 4),
                                   static_cast<int>(in.size()), max_dst);
    if (csz <= 0) throw std::runtime_error("LZ4_compress_default failed");
    out.resize(4 + csz);
    return out;
#else
    // Fallback: store uncompressed with size prefix (development only)
    std::vector<uint8_t> out(4 + in.size());
    uint32_t sz = static_cast<uint32_t>(in.size());
    std::memcpy(out.data(), &sz, 4);
    std::memcpy(out.data() + 4, in.data(), in.size());
    return out;
#endif
}

inline std::vector<uint8_t> compress_field_payload(const uint8_t* raw, size_t raw_bytes,
                                                   const Header& hdr, XorDeltaState* delta_state) {
    std::vector<uint8_t> work(raw, raw + raw_bytes);
    if ((hdr.compression & CMP_XOR_DELTA) && delta_state) {
        std::vector<uint8_t> d; delta_state->encode(work.data(), work.size(), d);
        work.swap(d);
    }
#ifdef CFD_ENABLE_ZFP
    if (hdr.compression & CMP_ZFP) {
        // Example: error-bounded ZFP compression (1D array of doubles/floats; for 3D use zfp_field_3d)
        zfp_type zt = (hdr.scalar_type == static_cast<uint8_t>(ScalarType::F64)) ? zfp_type_double : zfp_type_float;
        zfp_field* field = zfp_field_1d(work.data(), zt, work.size() / ((zt==zfp_type_double)?8:4));
        zfp_stream* zfp = zfp_stream_open(nullptr);
        zfp_stream_set_accuracy(zfp, 1e-4); // configure from runtime; absolute error bound
        size_t bufsize = zfp_stream_maximum_size(zfp, field);
        std::vector<uint8_t> out(bufsize);
        bitstream* stream = stream_open(out.data(), bufsize);
        zfp_stream_set_bit_stream(zfp, stream); zfp_stream_rewind(zfp);
        size_t zfpsize = zfp_compress(zfp, field);
        stream_close(stream); zfp_field_free(field); zfp_stream_close(zfp);
        if (zfpsize == 0) throw std::runtime_error("ZFP compression failed");
        out.resize(zfpsize);
        return out;
    }
#endif
    if (hdr.compression & CMP_LZ4) return lz4_compress(work);
    return work;
}

} // namespace cfdfld03::stream
```

```cpp
#pragma once
#include <vector>
#include <cstdint>
#include <array>
#include <span>
#include <cmath>
#include <limits>

namespace cfdfld03 {

struct Vec3 { double x{}, y{}, z{}; };
inline Vec3 operator+(Vec3 a, Vec3 b){return {a.x+b.x,a.y+b.y,a.z+b.z};}
inline Vec3 operator-(Vec3 a, Vec3 b){return {a.x-b.x,a.y-b.y,a.z-b.z};}
inline Vec3 operator*(double s, Vec3 a){return {s*a.x,s*a.y,s*a.z};}
inline Vec3 operator*(Vec3 a, double s){return {s*a.x,s*a.y,s*a.z};}
inline double dot(Vec3 a, Vec3 b){return a.x*b.x+a.y*b.y+a.z*b.z;}
inline Vec3 cross(Vec3 a, Vec3 b){return {a.y*b.z-a.z*b.y, a.z*b.x-a.x*b.z, a.x*b.y-a.y*b.x};}
inline double norm2(Vec3 a){return std::sqrt(dot(a,a));}

// CSR: offsets.size() == n+1, indices.size() == offsets[n]
struct CSR {
    std::vector<uint32_t> offsets;
    std::vector<uint32_t> indices;
    std::span<const uint32_t> row(uint32_t i) const {
        auto b = offsets[i], e = offsets[i+1];
        return {indices.data()+b, indices.data()+e};
    }
};

struct PolyMeshSoA {
    // Points
    std::vector<Vec3> points;                 // point coordinates

    // Faces
    std::vector<Vec3> face_centroids;         // Cf
    std::vector<Vec3> face_areas;             // Sf (area vector, outward from owner by convention)
    CSR face_points;                          // ordered point indices per face

    // Cells
    std::vector<Vec3> cell_centroids;         // Cc
    std::vector<double> cell_volumes;         // Vc
    CSR cell_faces;                           // CellFaceCSR: faces per cell

    // Connectivity
    std::vector<int32_t> owner;               // size = nFaces
    std::vector<int32_t> neighbour;           // size = nInternalFaces (-1 for boundary in some layouts) or nFaces with <0

    // Hilbert chunking (cell space)
    std::vector<uint32_t> cell_to_hilbert;    // optional mapping
    std::vector<uint32_t> hilbert_to_cell;    // reorder for chunk-contiguous traversal

    uint32_t nCells() const { return (uint32_t)cell_centroids.size(); }
    uint32_t nFaces() const { return (uint32_t)face_centroids.size(); }

    // Return neighbour cell across face f from cell c, or -1 if boundary/outside.
    int32_t face_neighbour_cell(uint32_t f, int32_t c) const {
        const int32_t o = owner[f];
        const int32_t nb = (f < neighbour.size()) ? neighbour[f] : -1;
        if (o == c) return nb;
        if (nb == c) return o;
        return -1; // not adjacent (should not happen)
    }

    // Oriented face area pointing outward from cell c.
    Vec3 outward_area(uint32_t f, int32_t c) const {
        Vec3 Sf = face_areas[f];
        if (owner[f] == c) return Sf;
        return Sf * -1.0;
    }
};

struct Aabb { Vec3 mn, mx; };
inline bool plane_intersects_aabb(const Aabb& b, Vec3 p0, Vec3 n) {
    // Compute projection interval radius of AABB onto plane normal
    Vec3 c{(b.mn.x+b.mx.x)*0.5, (b.mn.y+b.mx.y)*0.5, (b.mn.z+b.mx.z)*0.5};
    Vec3 e{(b.mx.x-b.mn.x)*0.5, (b.mx.y-b.mn.y)*0.5, (b.mx.z-b.mn.z)*0.5};
    const double r = e.x*std::abs(n.x) + e.y*std::abs(n.y) + e.z*std::abs(n.z);
    const double s = dot(c - p0, n);
    return std::abs(s) <= r;
}

} // namespace cfdfld03
```

### 4.2 Slicer, $Q$-criterion, $\lambda_2$ (`include/cfdfld03/kernels_slicer_vortex.hpp`)

```cpp
#pragma once
#include "mesh_soa.hpp"
#include <unordered_map>
#include <functional>
#include <algorithm>
#include <numeric>
#include <mutex>

namespace cfdfld03 {

struct SliceVertex {
    float px, py, pz;
    float nx, ny, nz;    // optional: plane normal or gradient direction for shading
    float scalar;
    float vx, vy, vz;    // optional interpolated vector
};

struct TriangleBuffer {
    std::vector<SliceVertex> vertices; // 3 * tri_count, GPU-ready flat fan/tri list
};

struct Plane { Vec3 p0; Vec3 n; }; // (x - p0).n = 0

inline double signed_distance(Vec3 x, const Plane& pl) { return dot(x - pl.p0, pl.n); }

struct EdgeHit {
    Vec3 x;
    double t;         // interpolation parameter on edge a->b
    uint32_t a, b;    // point ids (canonical a<b)
    bool valid{false};
};

inline bool edge_plane_intersect(Vec3 xa, Vec3 xb, double da, double db, Vec3& out, double& t) {
    const double denom = (da - db);
    if (std::abs(denom) < 1e-20) return false;
    t = da / denom; // da/(da-db), 0 at a, 1 at b
    if (t < -1e-12 || t > 1.0 + 1e-12) return false;
    t = std::clamp(t, 0.0, 1.0);
    out = xa + (xb - xa) * t;
    return true;
}

// Exact plane-polyhedron slicer (topological per-face edge intersections, stitched polygon).
// scalar_field: per-cell or per-point values; if per-cell, interpolation falls back to cell value
// (or provide point/face values as needed). Here: per-point scalar & per-point vector supported.
inline TriangleBuffer slice_plane_polyhedral(
    const PolyMeshSoA& mesh,
    const Plane& plane,
    const std::vector<Aabb>& chunk_aabbs,      // Hilbert chunk AABBs (size = ceil(nCells/65536))
    const std::vector<uint8_t>& active_chunks, // 0/1 mask
    const double* point_scalar,                // nullable, size nPoints
    const Vec3*   point_vector,                // nullable, size nPoints
    double cell_fallback_scalar = 0.0)
{
    TriangleBuffer out;
    if (mesh.cell_faces.offsets.empty()) return out;
    const uint32_t nChunks = (uint32_t)chunk_aabbs.size();
    std::vector<char> point_mark(mesh.points.size(), 0); // reused per cell minimally if needed

    auto make_vertex = [&](const Vec3& x, double scalar, Vec3 v) {
        SliceVertex sv{};
        sv.px=(float)x.x; sv.py=(float)x.y; sv.pz=(float)x.z;
        sv.nx=(float)plane.n.x; sv.ny=(float)plane.n.y; sv.nz=(float)plane.n.z;
        sv.scalar=(float)scalar; sv.vx=(float)v.x; sv.vy=(float)v.y; sv.vz=(float)v.z;
        return sv;
    };

    const uint32_t nCells = mesh.nCells();
    for (uint32_t chunk = 0; chunk < nChunks; ++chunk) {
        if (!active_chunks.empty() && !active_chunks[chunk]) continue;
        if (!plane_intersects_aabb(chunk_aabbs[chunk], plane.p0, plane.n)) continue;

        const uint32_t cBegin = chunk * 65536u;
        const uint32_t cEnd = std::min(nCells, cBegin + 65536u);
        for (uint32_t c = cBegin; c < cEnd; ++c) {
            // Collect intersection segments per face, stitch into polygon loop
            struct Seg { Vec3 a,b; double sa,sb; Vec3 va,vb; };
            std::vector<Seg> segs;
            auto faces = mesh.cell_faces.row(c);
            segs.reserve(faces.size());

            for (uint32_t f : faces) {
                auto pts = mesh.face_points.row(f);
                if (pts.size() < 3) continue;
                // find intersection points on face edges in order
                std::vector<Vec3> ip; std::vector<double> iscal; std::vector<Vec3> ivec;
                ip.reserve(2); iscal.reserve(2); ivec.reserve(2);

                for (size_t i = 0, m = pts.size(); i < m; ++i) {
                    uint32_t a = pts[i], b = pts[(i+1)%m];
                    const Vec3 xa = mesh.points[a], xb = mesh.points[b];
                    const double da = signed_distance(xa, plane), db = signed_distance(xb, plane);
                    Vec3 xh; double t;
                    if (edge_plane_intersect(xa, xb, da, db, xh, t)) {
                        double sa = point_scalar ? (point_scalar[a]*(1.0-t) + point_scalar[b]*t) : cell_fallback_scalar;
                        Vec3 va{0,0,0};
                        if (point_vector) va = point_vector[a]*(1.0-t) + point_vector[b]*t;
                        // avoid duplicate point insertion on vertex hit
                        if (ip.empty() || norm2(ip.back()-xh) > 1e-12) {
                            ip.push_back(xh); iscal.push_back(sa); ivec.push_back(va);
                        }
                    }
                }
                if (ip.size() >= 2) {
                    // for simple faces, 2 points; for rare non-convex/multi-cut, take first/last pairs
                    for (size_t k = 0; k + 1 < ip.size(); k += 2) {
                        segs.push_back({ip[k], ip[k+1], iscal[k], iscal[k+1], ivec[k], ivec[k+1]});
                    }
                }
            }
            if (segs.size() < 3) continue;

            // Stitch segments into ordered polygon (greedy endpoint chaining)
            std::vector<int> order; order.reserve(segs.size());
            std::vector<char> used(segs.size(), 0);
            order.push_back(0); used[0]=1;
            Vec3 cur = segs[0].b;
            for (size_t step = 1; step < segs.size(); ++step) {
                int best = -1; bool flip = false; double bestd = 1e-9;
                for (size_t j = 0; j < segs.size(); ++j) if (!used[j]) {
                    double d1 = norm2(segs[j].a - cur), d2 = norm2(segs[j].b - cur);
                    if (d1 < bestd) { bestd=d1; best=(int)j; flip=false; }
                    if (d2 < bestd) { bestd=d2; best=(int)j; flip=true; }
                }
                if (best < 0) { // relaxed tolerance fallback
                    for (size_t j = 0; j < segs.size(); ++j) if (!used[j]) { best=(int)j; flip=(norm2(segs[j].b-cur) < norm2(segs[j].a-cur)); break; }
                }
                if (best < 0) break;
                if (flip) { std::swap(segs[best].a,segs[best].b); std::swap(segs[best].sa,segs[best].sb); std::swap(segs[best].va,segs[best].vb); }
                used[best]=1; order.push_back(best); cur = segs[best].b;
            }
            if (order.size() < 3) continue;

            // Build polygon vertices (start point of each segment in chained order)
            std::vector<SliceVertex> poly; poly.reserve(order.size());
            for (int idx : order) {
                poly.push_back(make_vertex(segs[idx].a, segs[idx].sa, segs[idx].va));
            }

            // Triangle fan (convex in plane for convex-cell cuts; acceptable GPU output; for concave cuts add ear clipping)
            for (size_t i = 1; i + 1 < poly.size(); ++i) {
                out.vertices.push_back(poly[0]);
                out.vertices.push_back(poly[i]);
                out.vertices.push_back(poly[i+1]);
            }
        }
    }
    return out;
}

// --- Vortex identification: Q and lambda2 from velocity gradient tensor L_ij = du_i/dx_j ---
struct VortexMetrics { double Q; double lambda2; };

inline VortexMetrics compute_vortex_metrics(const double L[3][3]) {
    // S = 0.5*(L + L^T), Omega = 0.5*(L - L^T)
    double S[3][3], O[3][3];
    for (int i=0;i<3;++i) for (int j=0;j<3;++j) {
        S[i][j] = 0.5*(L[i][j] + L[j][i]);
        O[i][j] = 0.5*(L[i][j] - L[j][i]);
    }
    auto frob2 = [](const double A[3][3]) {
        double s=0; for(int i=0;i<3;++i) for(int j=0;j<3;++j) s += A[i][j]*A[i][j]; return s;
    };
    const double S2 = frob2(S), O2 = frob2(O);
    VortexMetrics vm{};
    vm.Q = 0.5 * (O2 - S2); // Q = 1/2 (||Omega||_F^2 - ||S||_F^2)

    // M = S^2 + Omega^2 (symmetric)
    auto mul = [](const double A[3][3], const double B[3][3], double C[3][3]) {
        for(int i=0;i<3;++i) for(int j=0;j<3;++j){
            double s=0; for(int k=0;k<3;++k) s += A[i][k]*B[k][j]; C[i][j]=s;
        }
    };
    double Ssq[3][3], Osq[3][3], M[3][3];
    mul(S,S,Ssq); mul(O,O,Osq);
    for(int i=0;i<3;++i) for(int j=0;j<3;++j) M[i][j] = Ssq[i][j] + Osq[i][j];

    // Analytic eigenvalues of symmetric 3x3 (trigonometric/Cardano-stable form)
    // Eigenvalues of A: l_k = q + 2p*cos(phi + 2k*pi/3)
    const double m00=M[0][0], m11=M[1][1], m22=M[2][2];
    const double m01=M[0][1], m02=M[0][2], m12=M[1][2];
    const double q = (m00 + m11 + m22) / 3.0;
    const double b00=m00-q, b11=m11-q, b22=m22-q;
    const double p2 = (b00*b00 + b11*b11 + b22*b22 + 2.0*(m01*m01 + m02*m02 + m12*m12)) / 6.0;
    if (p2 <= 1e-30) { vm.lambda2 = q; return vm; }
    const double p = std::sqrt(p2);
    // B = (M - qI)/p ; det(B)/2
    const double invp = 1.0 / p;
    const double B00=b00*invp, B11=b11*invp, B22=b22*invp, B01=m01*invp, B02=m02*invp, B12=m12*invp;
    const double detB = B00*(B11*B22 - B12*B12) - B01*(B01*B22 - B12*B02) + B02*(B01*B12 - B11*B02);
    double r = detB / 2.0;
    r = std::clamp(r, -1.0, 1.0);
    const double phi = std::acos(r) / 3.0;
    const double pi = 3.14159265358979323846;
    const double e1 = q + 2.0*p*std::cos(phi);
    const double e2 = q + 2.0*p*std::cos(phi + 2.0*pi/3.0);
    const double e3 = q + 2.0*p*std::cos(phi + 4.0*pi/3.0);
    double ev[3] = {e1,e2,e3};
    std::sort(ev, ev+3, std::greater<double>()); // e1>=e2>=e3
    vm.lambda2 = ev[1]; // second largest
    return vm;
}

// Parallel over cells (caller can thread; inner loop is vectorization-friendly)
inline void compute_vortex_field(const std::vector<std::array<double,9>>& gradU_cell, // row-major L per cell
                                 std::vector<double>& Q_out,
                                 std::vector<double>& lambda2_out) {
    const size_t n = gradU_cell.size();
    Q_out.resize(n); lambda2_out.resize(n);
    #pragma omp parallel for schedule(static) if(n > 4096)
    for (long long i = 0; i < (long long)n; ++i) {
        double L[3][3] = {{gradU_cell[i][0],gradU_cell[i][1],gradU_cell[i][2]},
                           {gradU_cell[i][3],gradU_cell[i][4],gradU_cell[i][5]},
                           {gradU_cell[i][6],gradU_cell[i][7],gradU_cell[i][8]}};
        auto vm = compute_vortex_metrics(L);
        Q_out[i] = vm.Q; lambda2_out[i] = vm.lambda2;
    }
}

} // namespace cfdfld03
```

## 5) Topological streamline integrator (RK4/Cash-Karp) + wall shear / $y^+$ / $q_w$

### 5.1 `include/cfdfld03/streamlines_wall.hpp`

```cpp
#pragma once
#include "mesh_soa.hpp"
#include <vector>
#include <array>
#include <functional>
#include <optional>
#include <limits>
#include <cmath>
#include <queue>
#include <unordered_set>

namespace cfdfld03 {

struct StreamPoint { Vec3 x; Vec3 u; int32_t cell; double t; double scalar; };

// Velocity evaluator: cell-linear reconstruction u(x)=u_c + gradU_c*(x-x_c) (or constant per cell)
using VelocityFn = std::function<Vec3(const Vec3& x, int32_t cell)>;

struct CashKarpCoeffs {
    // Butcher tableau (Cash-Karp 5(4))
    static constexpr double b5[6] = {37.0/378.0, 0.0, 250.0/621.0, 125.0/594.0, 0.0, 512.0/1771.0};
    static constexpr double b4[6] = {2825.0/27648.0, 0.0, 18575.0/48384.0, 13525.0/55296.0, 277.0/14336.0, 1.0/4.0};
};

inline Vec3 rk4_step(const Vec3& x, int32_t cell, double h, const VelocityFn& vel) {
    Vec3 k1 = vel(x, cell);
    Vec3 k2 = vel(x + k1*(0.5*h), cell);
    Vec3 k3 = vel(x + k2*(0.5*h), cell);
    Vec3 k4 = vel(x + k3*h,       cell);
    return x + (k1 + k2*2.0 + k3*2.0 + k4) * (h/6.0);
}

inline Vec3 cashkarp_step(const Vec3& x, int32_t cell, double h, const VelocityFn& vel, double* err_out=nullptr) {
    // Standard Cash-Karp stages (using cell-local/segment-local evaluation; for strict crossing use substeps)
    auto k1 = vel(x, cell);
    auto k2 = vel(x + k1*(h*0.2), cell);
    auto k3 = vel(x + (k1*(h*3.0/40.0) + k2*(h*9.0/40.0)), cell);
    auto k4 = vel(x + (k1*(h*0.3) - k2*(h*0.9) + k3*(h*1.2)), cell);
    auto k5 = vel(x + (k1*(h*-11.0/54.0) + k2*(h*2.5) - k3*(h*70.0/27.0) + k4*(h*35.0/27.0)), cell);
    auto k6 = vel(x + (k1*(h*1631.0/55296.0) + k2*(h*175.0/512.0) + k3*(h*575.0/13824.0) + k4*(h*44275.0/110592.0) + k5*(h*253.0/4096.0)), cell);
    Vec3 x5 = x + (k1*CashKarpCoeffs::b5[0] + k3*CashKarpCoeffs::b5[2] + k4*CashKarpCoeffs::b5[3] + k6*CashKarpCoeffs::b5[5]) * h;
    if (err_out) {
        Vec3 x4 = x + (k1*CashKarpCoeffs::b4[0] + k3*CashKarpCoeffs::b4[2] + k4*CashKarpCoeffs::b4[3] + k5*CashKarpCoeffs::b4[4] + k6*CashKarpCoeffs::b4[5]) * h;
        *err_out = norm2(x5 - x4);
    }
    return x5;
}

// Topological face-exit walker along a straight segment x -> x + d, starting in cell c.
// Zero global point-location after seeding. Uses: t_exit = min_{f in c, u·Sf>0} ((xf-x)·Sf)/(u·Sf)
inline int32_t walk_segment_across_cells(const PolyMeshSoA& mesh, Vec3 x0, Vec3 x1, int32_t start_cell,
                                         Vec3& x_end, double eps = 1e-12) {
    Vec3 d = x1 - x0;
    double seg_len = norm2(d);
    if (seg_len < 1e-15 || start_cell < 0) { x_end = x1; return start_cell; }
    Vec3 dir = d * (1.0 / seg_len);
    double t_remain = seg_len;
    Vec3 x = x0;
    int32_t cell = start_cell;

    for (int iter = 0; iter < 100000 && t_remain > eps; ++iter) {
        auto faces = mesh.cell_faces.row((uint32_t)cell);
        double t_exit = t_remain + 1.0; // beyond segment end => stay inside
        int32_t exit_face = -1;

        for (uint32_t f : faces) {
            Vec3 Sf = mesh.outward_area(f, cell);
            const double un = dot(dir, Sf);
            if (un <= 1e-14) continue; // not exiting through this face
            const double dist = dot(mesh.face_centroids[f] - x, Sf); // (xf-x)·Sf
            const double t = dist / un;
            if (t > eps && t < t_exit) { t_exit = t; exit_face = (int32_t)f; }
        }

        if (exit_face < 0 || t_exit >= t_remain) {
            x = x + dir * t_remain; t_remain = 0.0; break; // segment ends inside current cell
        }

        x = x + dir * t_exit;
        t_remain -= t_exit;
        int32_t nb = mesh.face_neighbour_cell((uint32_t)exit_face, cell);
        if (nb < 0) { x_end = x; return -1; } // boundary hit
        cell = nb;
        // nudge slightly inside next cell to avoid re-hitting same face numerically
        x = x + dir * (1e-9 * std::max(1.0, seg_len));
        t_remain = std::max(0.0, t_remain - 1e-9 * std::max(1.0, seg_len));
    }
    x_end = x;
    return cell;
}

struct StreamlineParams {
    double step_size = 1e-3;
    int    max_steps = 20000;
    bool   forward = true;
    bool   use_cash_karp = true;
};

inline std::vector<StreamPoint> integrate_streamline(const PolyMeshSoA& mesh, const VelocityFn& vel,
                                                     Vec3 seed, int32_t seed_cell, const StreamlineParams& p) {
    std::vector<StreamPoint> line;
    Vec3 x = seed; int32_t cell = seed_cell; double t = 0.0;
    const double hsign = p.forward ? 1.0 : -1.0;
    for (int i = 0; i < p.max_steps && cell >= 0; ++i) {
        Vec3 u = vel(x, cell);
        line.push_back({x,u,cell,t,0.0});
        if (norm2(u) < 1e-14) break;
        Vec3 x1 = p.use_cash_karp ? cashkarp_step(x, cell, hsign*p.step_size, vel)
                                  : rk4_step(x, cell, hsign*p.step_size, vel);
        Vec3 x_end; int32_t c1 = walk_segment_across_cells(mesh, x, x1, cell, x_end);
        if (norm2(x_end - x) < 1e-15) break;
        t += hsign * norm2(x_end - x);
        x = x_end; cell = c1;
    }
    return line;
}

// --- 3-ring wall face stencil collection ---
inline std::vector<int32_t> collect_n_ring_cells(const PolyMeshSoA& mesh, int32_t wall_owner_cell, int n_rings) {
    std::vector<int32_t> out;
    std::unordered_set<int32_t> vis;
    std::queue<std::pair<int32_t,int>> q;
    if (wall_owner_cell < 0) return out;
    q.push({wall_owner_cell, 0}); vis.insert(wall_owner_cell);
    while (!q.empty()) {
        auto [c,d] = q.front(); q.pop();
        out.push_back(c);
        if (d == n_rings) continue;
        for (uint32_t f : mesh.cell_faces.row((uint32_t)c)) {
            int32_t nb = mesh.face_neighbour_cell(f, c);
            if (nb >= 0 && !vis.count(nb)) { vis.insert(nb); q.push({nb,d+1}); }
        }
    }
    return out;
}

struct WallShearResult {
    Vec3 tau_w{0,0,0};      // wall shear stress vector [Pa]
    double u_tau{0.0};      // friction velocity [m/s]
    double y_plus{0.0};     // y+
    double q_w{0.0};        // wall heat flux [W/m^2], + into fluid by -k_eff*gradT·n convention
    double dnd_ut{0.0};     // |dUt/dn| at wall
};

inline void build_orthonormal_basis(Vec3 n, Vec3& t1, Vec3& t2) {
    n = n * (1.0 / std::max(norm2(n), 1e-30));
    Vec3 a = (std::abs(n.x) < 0.9) ? Vec3{1,0,0} : Vec3{0,1,0};
    t1 = cross(n, a); t1 = t1 * (1.0 / std::max(norm2(t1), 1e-30));
    t2 = cross(n, t1);
}

// 3-ring least-squares tangential velocity/temperature gradient reconstruction at wall face f.
// U: per-cell velocity, T: per-cell temperature (nullable for q_w), mu_eff/kappa_eff: per-cell or constant.
inline WallShearResult compute_wall_shear_3ring(
    const PolyMeshSoA& mesh, uint32_t wall_face,
    const std::vector<Vec3>& U_cell,
    const std::vector<double>* T_cell,
    double rho, double mu_eff_const, double kappa_eff_const,
    double nu_const /* kinematic viscosity for y+ if mu/rho not per-cell */)
{
    WallShearResult r{};
    const int32_t owner_cell = mesh.owner[wall_face];
    if (owner_cell < 0) return r;

    Vec3 nf = mesh.face_areas[wall_face];
    const double Af = std::max(norm2(nf), 1e-30);
    nf = nf * (1.0 / Af);
    // ensure normal points into fluid (out of owner into boundary => into domain opposite of owner outward?)
    // Convention: outward_area(f, owner) points from owner to outside; wall boundary normal into fluid is -outward from owner
    nf = mesh.outward_area(wall_face, owner_cell) * -1.0; nf = nf * (1.0/std::max(norm2(nf),1e-30));

    Vec3 t1,t2; build_orthonormal_basis(nf, t1, t2);
    const Vec3 xf = mesh.face_centroids[wall_face];

    auto cells = collect_n_ring_cells(mesh, owner_cell, 3);
    // Weighted least squares: u_t1 = g_n1*dn + g_t11*dt1 + g_t12*dt2 (no-slip wall)
    // Normal equations for 3 unknowns [g_n, g_t1c, g_t2c]
    double ATA[3][3] = {{0}}, ATb1[3]={0}, ATb2[3]={0}, ATbT[3]={0};
    double y1 = 0.0;

    for (int32_t c : cells) {
        Vec3 d = mesh.cell_centroids[(uint32_t)c] - xf;
        const double dn = dot(d, nf);
        if (dn <= 1e-12) continue;
        const double dt1 = dot(d,t1), dt2 = dot(d,t2);
        const double dist = std::max(norm2(d), 1e-12);
        const double w = 1.0 / (dist*dist); // distance weighting (favor near-wall)
        const double phi[3] = {dn, dt1, dt2};

        if (c == owner_cell) y1 = dn; // first off-wall distance estimate

        Vec3 u = U_cell[(uint32_t)c];
        const double ut1 = dot(u,t1), ut2 = dot(u,t2);
        const double Tc = (T_cell && (size_t)c < T_cell->size()) ? (*T_cell)[(uint32_t)c] : 0.0;

        for(int i=0;i<3;++i){
            for(int j=0;j<3;++j) ATA[i][j] += w*phi[i]*phi[j];
            ATb1[i] += w*phi[i]*ut1;
            ATb2[i] += w*phi[i]*ut2;
            ATbT[i] += w*phi[i]*Tc;
        }
    }

    auto solve3 = [](double A[3][3], const double b[3], double x[3])->bool{
        // Cramer's rule / Gaussian elimination (tiny system)
        double M[3][4]={{A[0][0],A[0][1],A[0][2],b[0]},{A[1][0],A[1][1],A[1][2],b[1]},{A[2][0],A[2][1],A[2][2],b[2]}};
        for(int i=0;i<3;++i){
            int piv=i; for(int r=i+1;r<3;++r) if(std::abs(M[r][i])>std::abs(M[piv][i])) piv=r;
            if(std::abs(M[piv][i]) < 1e-20) return false;
            if(piv!=i) for(int k=i;k<4;++k) std::swap(M[i][k],M[piv][k]);
            double inv=1.0/M[i][i];
            for(int k=i;k<4;++k) M[i][k]*=inv;
            for(int r=0;r<3;++r) if(r!=i){ double f=M[r][i]; for(int k=i;k<4;++k) M[r][k]-=f*M[i][k]; }
        }
        x[0]=M[0][3]; x[1]=M[1][3]; x[2]=M[2][3]; return true;
    };

    double g1[3]={0}, g2[3]={0}, gT[3]={0};
    double A1[3][3],A2[3][3],A3[3][3];
    std::memcpy(A1,ATA,sizeof(ATA)); std::memcpy(A2,ATA,sizeof(ATA)); std::memcpy(A3,ATA,sizeof(ATA));
    const bool ok1 = solve3(A1, ATb1, g1);
    const bool ok2 = solve3(A2, ATb2, g2);
    const bool okT = (T_cell != nullptr) ? solve3(A3, ATbT, gT) : false;

    // g[0] = dUt1/dn, g2[0] = dUt2/dn
    Vec3 dUt_dn = t1*(ok1?g1[0]:0.0) + t2*(ok2?g2[0]:0.0);
    r.dnd_ut = norm2(dUt_dn);
    r.tau_w = dUt_dn * mu_eff_const; // tau_w = mu_eff * (dU_t/dn)_w
    const double tau_mag = norm2(r.tau_w);
    r.u_tau = std::sqrt(std::max(tau_mag / std::max(rho, 1e-30), 0.0));
    const double nu = (nu_const > 0.0) ? nu_const : (mu_eff_const / std::max(rho,1e-30));
    r.y_plus = (y1 > 0.0 && nu > 0.0) ? (y1 * r.u_tau / nu) : 0.0;

    // q_w = -k_eff * grad(T)·n, grad(T)·n ~ dT/dn = gT[0]
    if (okT) r.q_w = -kappa_eff_const * gT[0];
    return r;
}

} // namespace cfdfld03
```

## 6) Boundary patch integrators + Paket 4 telemetry emission

### 6.1 `include/cfdfld03/boundary_integrals.hpp`

```cpp
#pragma once
#include "mesh_soa.hpp"
#include "streamlines_wall.hpp"
#include <string>
#include <vector>
#include <unordered_map>
#include <unordered_set>
#include <sstream>
#include <iomanip>
#include <cmath>

namespace cfdfld03 {

struct BoundaryPatch {
    std::string name;
    std::vector<uint32_t> face_ids; // boundary faces
};

struct AeroCoeffsConfig {
    Vec3 force_dir_lift{0,1,0};
    Vec3 force_dir_drag{1,0,0};
    Vec3 force_dir_side{0,0,1};
    Vec3 moment_center{0,0,0};
    Vec3 moment_axis{0,0,1};   // Cm about this axis
    double rho_ref{1.225};
    double u_ref{1.0};
    double a_ref{1.0};
    double l_ref{1.0};
    double p_ref{0.0};
    double T_ref{300.0};
};

struct PatchIntegrals {
    Vec3 Fp{0,0,0};
    Vec3 Fv{0,0,0};
    Vec3 M{0,0,0};
    double Cd{0}, Cl{0}, Cs{0}, Cm{0};
    double mdot{0.0};
    double dp0_area{0.0};
    double dp0_mdot{0.0};
    double Nu_mean{0.0};
    double area{0.0};
};

inline PatchIntegrals integrate_patch_set(
    const PolyMeshSoA& mesh,
    const std::vector<uint32_t>& faces,
    const std::vector<double>& p_cell,         // pressure per cell
    const std::vector<double>& T_cell,         // temperature per cell
    const std::vector<double>& rho_cell,       // density per cell
    const std::vector<Vec3>&   U_cell,         // velocity per cell
    const std::vector<Vec3>&   tauw_face,      // wall shear vector per face (or precomputed for wall faces)
    const AeroCoeffsConfig& cfg,
    double kappa_ref_for_nu = 0.026,           // reference conductivity for Nu normalization
    double Lchar_for_nu = 1.0)
{
    PatchIntegrals I{};
    const double qinf = 0.5 * cfg.rho_ref * cfg.u_ref * cfg.u_ref;
    const double denomF = std::max(qinf * cfg.a_ref, 1e-30);
    const double denomM = std::max(qinf * cfg.a_ref * cfg.l_ref, 1e-30);

    double sum_dp0A = 0.0, sum_A = 0.0, sum_dp0_m = 0.0, sum_abs_m = 0.0;
    double sum_hA = 0.0; // Nu mean via h = q_w/(T_w-T_ref) proxy if needed
    int nNu = 0;

    for (uint32_t f : faces) {
        const int32_t oc = mesh.owner[f];
        if (oc < 0) continue;
        const Vec3 Sf = mesh.outward_area(f, oc); // outward from fluid domain
        const double Af = std::max(norm2(mesh.face_areas[f]), 1e-30);
        const Vec3 xf = mesh.face_centroids[f];
        const double pf = p_cell[(size_t)oc] - cfg.p_ref; // simple owner reconstruction; replace with boundaryField value if available
        const Vec3 uf = U_cell[(size_t)oc];
        const double rhof = rho_cell[(size_t)oc];
        const double Tf = T_cell[(size_t)oc];

        // Pressure force: Fp = sum_f (p_f - p_ref)*Sf  (Sf outward from fluid/body convention as configured)
        I.Fp = I.Fp + Sf * pf;

        // Viscous force: Fv = -sum_f tau_w,f * |Sf|
        if (f < tauw_face.size()) {
            I.Fv = I.Fv - tauw_face[f] * Af;
        }

        // Moment about center
        const Vec3 r = xf - cfg.moment_center;
        const Vec3 dF = Sf * pf + ((f < tauw_face.size()) ? (tauw_face[f] * -Af) : Vec3{0,0,0});
        I.M = I.M + cross(r, dF);

        // Mass flow: mdot_f = rho_f * (u_f · Sf), outward positive
        const double mdot_f = rhof * dot(uf, Sf);
        I.mdot += mdot_f;

        // Total pressure and losses
        const double p0 = p_cell[(size_t)oc] + 0.5 * rhof * dot(uf, uf);
        const double p0ref = cfg.p_ref + 0.5 * cfg.rho_ref * cfg.u_ref * cfg.u_ref;
        const double dp0 = p0ref - p0;
        sum_dp0A += dp0 * Af; sum_A += Af;
        sum_dp0_m += dp0 * std::abs(mdot_f); sum_abs_m += std::abs(mdot_f);

        // Mean Nu (placeholder local estimate if h known externally; integrate q_w/(Tw-Tref)*L/k)
        // In production pass precomputed q_w per face: Nu_f = (q_w * Lchar)/(kappa_ref*(T_w-T_ref))
        (void)Tf; (void)kappa_ref_for_nu; (void)Lchar_for_nu; nNu++;

        I.area += Af;
    }

    I.dp0_area = (sum_A > 0) ? (sum_dp0A / sum_A) : 0.0;
    I.dp0_mdot = (sum_abs_m > 0) ? (sum_dp0_m / sum_abs_m) : 0.0;
    I.Nu_mean = 0.0; // set from explicit q_w/T_w integration below when available

    const Vec3 Ftot = I.Fp + I.Fv;
    I.Cd = dot(Ftot, cfg.force_dir_drag) / denomF;
    I.Cl = dot(Ftot, cfg.force_dir_lift) / denomF;
    I.Cs = dot(Ftot, cfg.force_dir_side) / denomF;
    I.Cm = dot(I.M, cfg.moment_axis) / denomM;
    return I;
}

inline double integrate_mean_nusselt(const std::vector<uint32_t>& faces,
                                     const std::vector<double>& qw_face,
                                     const std::vector<double>& Tw_face,
                                     const std::vector<double>& Af_face,
                                     double T_ref, double Lchar, double kappa_ref) {
    double num=0.0, den=0.0;
    for (uint32_t f : faces) {
        const double dT = std::max(Tw_face[f] - T_ref, 1e-12);
        const double h = qw_face[f] / dT;
        const double Nu = h * Lchar / std::max(kappa_ref, 1e-30);
        num += Nu * Af_face[f]; den += Af_face[f];
    }
    return den > 0 ? num/den : 0.0;
}

// Emit Paket 4 NDJSON telemetry line (one JSON object per line)
inline std::string emit_paket4_telemetry(uint64_t step, double sim_time,
                                         const std::string& patch_set_name,
                                         const PatchIntegrals& I) {
    std::ostringstream os;
    os.setf(std::ios::fixed); os << std::setprecision(9);
    os << "{"
       << "\"paket\":4,"
       << "\"type\":\"boundary_integrals\","
       << "\"step\":" << step << ","
       << "\"time\":" << sim_time << ","
       << "\"patch_set\":\"" << patch_set_name << "\","
       << "\"Fp\":[" << I.Fp.x << "," << I.Fp.y << "," << I.Fp.z << "],"
       << "\"Fv\":[" << I.Fv.x << "," << I.Fv.y << "," << I.Fv.z << "],"

    return os.str();
}
```

```rust
// crates/foam_fast_io/src/kernels.rs
use rayon::prelude::*;

#[derive(Clone, Copy, Debug, Default)]
pub struct GradU(pub [[f64; 3]; 3]); // L_ij = du_i/dx_j

#[inline]
pub fn vortex_metrics(l: &[[f64; 3]; 3]) -> (f64, f64) {
    let mut s = [[0.0f64; 3]; 3];
    let mut o = [[0.0f64; 3]; 3];
    for i in 0..3 { for j in 0..3 {
        s[i][j] = 0.5 * (l[i][j] + l[j][i]);
        o[i][j] = 0.5 * (l[i][j] - l[j][i]);
    }}
    let frob2 = |a: &[[f64;3];3]| -> f64 { a.iter().flat_map(|r| r.iter()).map(|v| v*v).sum() };
    let q = 0.5 * (frob2(&o) - frob2(&s));

    let mul = |a: &[[f64;3];3], b: &[[f64;3];3]| -> [[f64;3];3] {
        let mut c = [[0.0;3];3];
        for i in 0..3 { for j in 0..3 { for k in 0..3 { c[i][j] += a[i][k]*b[k][j]; }}}
        c
    };
    let ss = mul(&s,&s); let oo = mul(&o,&o);
    let mut m = [[0.0;3];3];
    for i in 0..3 { for j in 0..3 { m[i][j] = ss[i][j] + oo[i][j]; } }

    let tr = m[0][0]+m[1][1]+m[2][2];
    let qinv = tr / 3.0;
    let b00=m[0][0]-qinv; let b11=m[1][1]-qinv; let b22=m[2][2]-qinv;
    let p1 = m[0][1]*m[0][1] + m[0][2]*m[0][2] + m[1][2]*m[1][2];
    let p2 = (b00*b00 + b11*b11 + b22*b22 + 2.0*p1) / 6.0;
    let lambda2 = if p2 <= 1e-30 { qinv } else {
        let p = p2.sqrt();
        let (b01,b02,b12) = (m[0][1]/p, m[0][2]/p, m[1][2]/p);
        let (bb00,bb11,bb22) = (b00/p,b11/p,b22/p);
        let detb = bb00*(bb11*bb22 - b12*b12) - b01*(b01*bb22 - b12*b02) + b02*(b01*b12 - bb11*b02);
        let r = (detb / 2.0).clamp(-1.0, 1.0);
        let phi = r.acos() / 3.0;
        let pi = std::f64::consts::PI;
        let mut ev = [qinv + 2.0*p*phi.cos(), qinv + 2.0*p*(phi + 2.0*pi/3.0).cos(), qinv + 2.0*p*(phi + 4.0*pi/3.0).cos()];
        ev.sort_by(|a,b| b.partial_cmp(a).unwrap());
        ev[1]
    };
    (q, lambda2)
}

pub fn compute_vortex_field_parallel(grads: &[[[f64;3];3]]) -> (Vec<f64>, Vec<f64>) {
    let res: Vec<(f64,f64)> = grads.par_iter().map(vortex_metrics).collect();
    let mut q = Vec::with_capacity(res.len());
    let mut l2 = Vec::with_capacity(res.len());
    for (a,b) in res { q.push(a); l2.push(b); }
    (q, l2)
}
```

```cpp
// src/cfdfld03_insitu_tick.cpp (illustrative integration point inside solver time-step)
#include "cfdfld03/protocol.hpp"
#include "cfdfld03/shm_ring.hpp"
#include "cfdfld03/kernels_slicer_vortex.hpp"
#include "cfdfld03/boundary_integrals.hpp"
#include "cfdfld03/delta_stream.hpp"
#include <chrono>

using namespace cfdfld03;

struct InsituEngine {
    shm::ProducerRing shm{"/cfdfld03_field_ring", 3 /*triple-buffer*/, 64u<<20 /*64 MiB slot*/};
    stream::XorDeltaState delta;
    uint64_t seq_counter{0};

    void publish_scalar_field(const PolyMeshSoA& mesh,
                              const std::vector<float>& cell_scalar,
                              const std::vector<ChunkEntry>& chunk_dir,
                              uint32_t mesh_rev, uint64_t step, double time,
                              const int8_t dims[7]) {
        Header h{};
        std::memcpy(h.magic, kMagic.data(), 8);
        h.mesh_revision = mesh_rev;
        h.chunk_count = (uint32_t)chunk_dir.size();
        h.step_index = step;
        h.sim_time_f64 = time;
        std::memcpy(h.dims, dims, 7);
        h.field_location = (uint8_t)FieldLocation::Cell;
        h.value_source = (uint8_t)ValueSource::BoundaryField;
        h.compression = CMP_LZ4 | CMP_XOR_DELTA; // or CMP_ZFP
        h.scalar_type = (uint8_t)ScalarType::F32;
        h.components = 1;
        h.chunk_shift = 16;
        h.header_version = kHeaderVersion;
        h.total_values = cell_scalar.size();
        h.chunk_dir_offset = sizeof(SlotEnvelope);
        h.payload_offset = h.chunk_dir_offset + (uint32_t)(chunk_dir.size()*sizeof(ChunkEntry));

        const uint8_t* raw = reinterpret_cast<const uint8_t*>(cell_scalar.data());
        size_t raw_bytes = cell_scalar.size()*sizeof(float);
        auto payload = stream::compress_field_payload(raw, raw_bytes, h, &delta);

        uint64_t seq; uint32_t slot_idx;
        uint8_t* slot = shm.begin_write(seq, slot_idx);
        auto* env = reinterpret_cast<SlotEnvelope*>(slot);
        env->frame_sequence = seq;
        env->wall_clock_ns = (uint64_t)std::chrono::duration_cast<std::chrono::nanoseconds>(
            std::chrono::steady_clock::now().time_since_epoch()).count();
        env->checksum_crc32c = 0;
        env->header = h;
        env->payload_bytes = sizeof(SlotEnvelope) + chunk_dir.size()*sizeof(ChunkEntry) + payload.size();

        std::memcpy(slot + h.chunk_dir_offset, chunk_dir.data(), chunk_dir.size()*sizeof(ChunkEntry));
        std::memcpy(slot + h.payload_offset, payload.data(), payload.size());
        shm.commit_write(slot_idx, seq, (uint32_t)env->payload_bytes);
    }

    void compute_and_emit_aero(const PolyMeshSoA& mesh,
                               const std::vector<uint32_t>& wing_faces,
                               const std::vector<double>& p, const std::vector<double>& T,
                               const std::vector<double>& rho, const std::vector<Vec3>& U,
                               const std::vector<Vec3>& tauw_face,
                               uint64_t step, double time,
                               std::string& ndjson_out /* append to Paket 4 stream */) {
        AeroCoeffsConfig cfg; cfg.p_ref = 101325.0; cfg.rho_ref = 1.225; cfg.u_ref = 50.0; cfg.a_ref = 2.0; cfg.l_ref = 1.0;
        PatchIntegrals I = integrate_patch_set(mesh, wing_faces, p, T, rho, U, tauw_face, cfg);
        ndjson_out += emit_paket4_telemetry(step, time, "wing", I);
    }
};
```

## 10) Integration and correctness notes (production checklist)

- **Protocol/layout:** `Header` is 64 bytes, `ChunkEntry` 64 bytes, both `packed`/`repr(C)`. Add `static_assert`/unit tests on every target ABI and CI (x86_64, ARM64). Keep little-endian; if a big-endian platform is introduced, add an explicit endian flag in a future header version.
- **Hilbert chunking (65,536 cells):** `chunk_shift=16`. Store chunk directory in Hilbert order with per-chunk AABB and value range for space-skipping (plane-AABB, frustum, iso-range). Chunks are the unit of compression, streaming, and GPU upload.
- **SPMC SHM:** seqlock-style validation (`seq` read before/after copy) ensures readers never observe torn frames; `published_sequence` is acquire/release. Triple-buffer (`slot_count=3`) gives latest-frame semantics ideal for 60–120 FPS UI; increase slots for short rewind/history.
- **XOR-delta:** reset delta state on `mesh_revision` change, stream restart, or detected discontinuity (sequence gap policy). For multi-component fields, delta per lane/element in value order.
- **ZFP:** protocol flag `CMP_ZFP` means error-bounded block compression; production deployments should use `libzfp` (`zfp_stream_set_accuracy`) to guarantee bound. LZ4 path is lossless.
- **Slicer:** exact per-face edge-plane intersections with topological segment stitching; chunk AABB culling is mandatory for large meshes. For concave cut polygons, replace fan triangulation with ear-clipping in the plane (rare for convex polyhedra but possible in general polyhedral sets).
- **$Q/\lambda_2$:** uses `L_ij=∂u_i/∂x_j`, $S=(L+L^T)/2$, $\Omega=(L-L^T)/2$, $Q=\frac{1}{2}(||\Omega||_F^2-||S||_F^2)$, $\lambda_2$ = middle eigenvalue of $M=S^2+\Omega^2$ via trigonometric Cardano form for symmetric $3\times3$.
- **Streamlines:** RK4/Cash-Karp displacement with topological face-exit walking `t_exit = min_{f, u·Sf>0} ((xf-x)·Sf)/(u·Sf)` across polyhedral cells (no global point location after seeding). Handle boundary exits, zero-velocity stagnation, and max-step termination.
- **Wall reconstruction:** 3-ring face-neighbor stencil, distance-weighted least squares in local $(t_1,t_2,n)$ basis for $dU_t/dn$ and $dT/dn$, yielding $\tau_w$, $u_\tau$, $y^+$, $q_w=-k_{\text{eff}}\nabla T\cdot n$.
- **Paket 4 NDJSON:** emit one compact JSON object per telemetry update (`Fp,Fv,Cd,Cl,Cs,Cm,mdot,dp0_area_weighted,dp0_massflow_weighted,Nu_mean`) on the existing JSON-RPC 2.0/NDJSON IPC channel; keep binary field transport in CFDFLD03 only.

This package gives a complete, end-to-end reference for `Paket 3 (CFDFLD03)`: wire format, zero-copy local IPC, remote delta streaming, in-situ kernels, and live aerodynamic/thermal integrals ready to connect to your C++20/Rust multiphysics cockpit.
